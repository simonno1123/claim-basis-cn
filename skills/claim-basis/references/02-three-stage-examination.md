# 02 三段式检验

每一个候选请求权，都依次回答三个问题。前一段不成立，后面不必再查，但要写明停在哪一段、因为什么。

## 第一段：请求权是否已经产生

检验请求权基础规范的**全部构成要件**是否齐备。

- 把规范拆成要件清单（要件来自数据层返回的条文与通行的要件理解，交律师确认）。
- 逐项涵摄，方法见 `03-subsumption-and-burden.md`。
- 同时检查**权利未发生的抗辩**：对方主张某一要件不存在，或主张存在阻止权利发生的事由。

常见的权利未发生抗辩：

| 类型 | 例 |
| --- | --- |
| 合同未成立 | 要约承诺不一致、缺少必要条款 |
| 合同无效 | 违反强制性规定或公序良俗、恶意串通、虚假意思表示 |
| 合同未生效 | 附生效条件未成就、须经批准未批准 |
| 主体问题 | 无民事行为能力、无代理权且未追认、主体不适格 |
| 要件事实不存在 | 未交付、未提供服务、无损害、无因果关系 |

## 第二段：请求权是否未消灭

请求权产生后，可能因法定事由消灭。检查**权利消灭的抗辩**：

| 类型 | 例 |
| --- | --- |
| 清偿 | 已付款、已交付、第三人代为履行 |
| 抵销 | 法定抵销、约定抵销 |
| 提存 | 依法提存 |
| 免除 | 债权人放弃债权 |
| 混同 | 债权债务归于一人 |
| 解除 | 合同解除后，履行请求消灭，转为返还、赔偿请求 |
| 撤销 | 可撤销的法律行为被撤销，自始失去效力（这一项也可归入第一段，按实际情况写明） |

注意：部分消灭的，计算剩余部分；解除不是简单消灭，而是转换成新的请求权，要回到 `01-search-order.md` 重新排查。

## 第三段：请求权是否可以行使

请求权存在且未消灭，但对方可能享有拒绝履行的权利。检查**抗辩权**（权利阻止的抗辩）：

| 类型 | 要点 |
| --- | --- |
| 诉讼时效 | 时效届满后义务人可拒绝履行；**须由当事人主张，法院不主动适用**；注意起算、中止、中断 |
| 同时履行抗辩权 | 双务合同、互负债务、没有先后履行顺序 |
| 先履行抗辩权 | 有先后顺序，先履行一方未履行或履行不符合约定 |
| 不安抗辩权 | 先履行一方有确切证据证明对方丧失或可能丧失履行能力 |
| 一般保证人的先诉抗辩权 | 主债务未经审判或仲裁、未就主债务人财产依法强制执行仍不能履行之前 |
| 履行期限未届至 | 请求提前履行 |

抗辩权与前两段抗辩的区别：前两段的事由一经查明，法院应当考虑；抗辩权须由义务人主张才发生效力（诉讼时效最典型）。输出时把"对方是否已主张"单列一栏。

## 输出

```text
候选：[规范名称]
第一段 已产生：成立 / 不成立 / 待证（要件清单见涵摄表）
  权利未发生的抗辩：[有 / 无 / 可能]，内容……
第二段 未消灭：成立 / 部分消灭（剩余……）/ 已消灭
  权利消灭的抗辩：……
第三段 可行使：成立 / 受阻
  抗辩权：[类型]，对方是否已主张：是 / 否 / 未知
结论：在所列事实与依据下，本请求权【可被证明 / 不能被证明 / 取决于以下待证事实】
```
